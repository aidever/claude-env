🌐 代理设置

容器里的所有流量（Claude、Codex、npm…）都会走这个 SOCKS5 代理；Looklook 自动直连。

代理软件开在这台电脑上？

地址填 host.docker.internal，端口填代理软件的 SOCKS5 端口（Clash 系列通常是 7890 或 7891），并在代理软件里打开「允许局域网连接 / Allow LAN」。

网络检测
在容器内同时请求 ip.me 等多个站点，最快返回的作为结果：能拿到 IP 就说明网络已通，这个 IP 就是代理出口。

🔎 IP 质量检测

在容器里运行 xykt/IPQuality，检测代理出口 IP 的类型、风险评分、流媒体和 AI 服务解锁情况。首次运行会自动安装依赖，需要 1-3 分钟。

🔀 分流规则

一行一条 Mihomo 规则，不写策略，例如 DOMAIN-SUFFIX,example.com、IP-CIDR,1.2.3.4/32,no-resolve。保存后调用容器内 mihomo-reload 立即生效，不用重启。
